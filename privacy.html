Privacy Policy

Last updated: 7 November 2026

Channel Assistant is a personal tool that its owner uses only with the owner's own YouTube channels.

Data accessed

With the owner's permission, the tool reads channel information and analytics, uploads videos, and edits titles, descriptions and other metadata of the owner's own videos, through the YouTube API.

Storage and sharing

Access tokens are stored only on the owner's own computer. No data is sent to, sold to, or shared with any third party. No data is collected from other users, because there are none.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
